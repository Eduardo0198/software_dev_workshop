Preguntas Teóricas

Diferencia entre Internet y WWW

Internet es la infraestructura global de redes interconectadas. La World Wide Web es un sistema de información que utiliza Internet para acceder a páginas web mediante HTTP.

Partes de un URL

Protocolo (https), dominio, ruta, parámetros y fragmentos.

Métodos HTTP

  • GET: Solicita datos.
  • POST: Envía datos al servidor.
  • PUT: Reemplaza un recurso.
  • PATCH: Modifica parcialmente.
  • DELETE: Elimina un recurso.
  • HEAD: Solicita solo encabezados.

¿Qué método usar en formularios?

POST, porque envía datos sensibles en el cuerpo de la petición.

Código 200

Significa que la solicitud fue exitosa. No hubo error.

Error 404

Indica que el recurso no fue encontrado. Puede ser responsabilidad del desarrollador si el enlace está mal configurado.

Error 500

Es un error interno del servidor. Sí es responsabilidad del desarrollador.

HTML4 vs HTML5

HTML5 introduce etiquetas semánticas como header, footer, section y soporte multimedia nativo.
