Descripción del proyecto

En este laboratorio se desarrolló una pequeña aplicación web tipo catálogo utilizando Bootstrap. El objetivo de este laborttorio es poder probar que frameworks de estilo nos puede ayudar para nuestro Catologo de PPG El tema que elegi yo fue un catálogo de personajes de Marvel, con el objetivo de aplicar componentes visuales como navbar, cards, botones, badges, contenedores responsivos y modales.

Además, esta base podrá reutilizarse en el siguiente laboratorio para agregar funcionalidades dinámicas con JavaScript, como filtros, búsqueda o favoritos y mas

Preguntas del laboratorio

Un framework de estilos es una herramienta que proporciona clases, componentes y estructuras visuales predefinidas para diseñar interfaces web de forma más rápida, consistente y responsiva.

Se eligió Bootstrap porque facilita el diseño visual de páginas web, ofrece componentes reutilizables como cards, botones, navbar y acordeones, y permite crear interfaces responsivas de manera rápida.

Bootstrap ahorra tiempo de desarrollo, mejora la consistencia visual, facilita la adaptabilidad a distintos dispositivos y proporciona una gran variedad de componentes ya listos para usar.

La experiencia del usuario mejoró gracias a una interfaz más ordenada, atractiva y fácil de navegar. El uso de cards, badges, botones y un modal permite consultar información de forma clara y visual.
