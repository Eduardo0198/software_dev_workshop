Preguntas Teóricas

1) Diferencia entre Internet y WWW

Internet es la red; la WWW es el servicio de páginas/enlaces que usa HTTP/HTTPS.

2) Partes de un URL

Protocolo, dominio/host, ruta, (puerto opcional), query/parámetros y fragmento.

3) Propósito de métodos HTTP

  • GET: obtener
  • HEAD: headers
  • POST: enviar/crear
  • PUT: reemplazar
  • PATCH: modificar parcial
  • DELETE: eliminar

4) Método al enviar login (usuario/contraseña)

POST, porque manda datos en el cuerpo (no en la URL) y es más apropiado para datos sensibles (con HTTPS).

5) Método al abrir una página escribiendo un URL

GET.

6) Código HTTP 200

Solicitud exitosa. No indica error.

7) Error 404: ¿es responsabilidad del desarrollador?

Depende: si hay enlaces/rutas mal hechas en el sitio, sí; si el usuario escribió mal la URL, no necesariamente.

8) Error 500: ¿es responsabilidad del desarrollador?

Generalmente sí, es un error interno del servidor (código/configuración/BD).

9) ¿Qué significa deprecated en HTML5? (ejemplos)

Que ya no se recomienda usar. Ejemplos: <font>, <center>, <frameset>/<frame>.

10) Diferencias principales HTML4 vs HTML5

HTML5 agrega semántica, multimedia nativa (audio/video) y mejores formularios; reduce etiquetas de presentación.

11) Componentes de estructura y estilo de una tabla

Estructura: table, thead, tbody, tfoot, tr, th, td. Estilo: se controla con CSS (bordes, padding, alineación, colores).

12) Principales controles de una forma HTML5

input (text, email, password, date, number, etc.), textarea, select, button.

13) Soporte HTML5 del navegador

Navegador: Google Chrome. Soporte: alto (comprobar en html5test.com y pegar puntaje).

14) Ciclo de vida de los sistemas de información

Planeación, análisis, diseño, implementación, operación, mantenimiento y retiro.

15) Ciclo de desarrollo de sistemas de información (SDLC)

Requerimientos, diseño, desarrollo, pruebas, despliegue y mantenimiento (iterable en ágil).
